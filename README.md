# 🐻💖 Mau Ngedate Nggak?

Website lucu yang ngajak ngedate pasangan! Ada bear animated yang bisa sedih, happy, dramatic, sampe pingsan kalau terus ditolak 😂

## ✨ Fitur

- 🐻 **Bear Animated** — gerak lucu: idle goyang, blink, sedih nangis, happy lompat-lompat, dramatic tremor, sampe pingsan!
- 🔘 **Tombol No makin kecil** — scale down setiap klik, sampe hilang total
- 💖 **Tombol Yes makin besar** — scale up terus sampe 5x ukuran asli
- ⚡ **Efek Dramatis** — screen shake, petir, thunder, bear pingsan pas No terakhir
- 🎵 **Musik Romantis** — synth melody lucu (toggle 🎵 di pojok kanan atas)
- 📅 **Form Kencan** — minta tanggal, jam, dan tempat setelah diterima
- 🎉 **Confetti** — particle explosion warna-warni
- 💬 **Share** — langsung share via WhatsApp atau copy

## 🚀 Deploy

Website ini di-deploy via Vercel. Buka langsung tanpa server!

## 🛠️ Tech Stack

- Vanilla HTML/CSS/JavaScript
- Web Audio API (sound effects & music, no external files)
- SVG animated bear
- Canvas API (confetti particles)
